# Credits and provenance

## Original firmware — trentct

**KK / M5Stack StopWatch Avatar** was created by **trentct and contributors**.
CodexPetFirmware is derived from that project:

[https://github.com/Trentct/m5stack-stopwatch-avatar](https://github.com/Trentct/m5stack-stopwatch-avatar)

The fork started at commit `204963257cb4dc2f3d7501eff900897bac55ef82`.
The original procedural avatar engine, hardware integration and interactions
form the foundation of the CodexPet firmware. Original authorship, AGPL-3.0-or-later
terms and all five upstream Git commits remain in this repository's history.

## CodexPet — RunDeleteParadox

RunDeleteParadox and contributors develop the CodexPet firmware adaptations,
Windows Hub and Codex lifecycle plugin. This attribution covers those additions
and modifications, while original upstream rights remain intact.

## Other projects

- **Bible Strong Avatar Lab:** architectural inspiration acknowledged by the

- **.NET Foundation, Microsoft and contributors:** the Windows runtime and packages.
